Quick install

Installs AltPing for the current user, without root, and adds it to the app menu. It picks the x64 or arm64 build for your machine.

wget -qO- https://github.com/ipoluianov/altping/releases/latest/download/linux-install.sh | bash

Notes

  • Ping without root. AltPing uses the kernel's unprivileged ICMP sockets. They are allowed by default on systemd 243 and later (Ubuntu 20.04+, Debian 11+, Fedora, Arch). If ping fails for every host and the status bar shows no mode, allow them for all users. TCP checks work in any case.
    echo 'net.ipv4.ping_group_range = 0 2147483647' | sudo tee /etc/sysctl.d/99-ping.conf && sudo sysctl --system
  • System tray. KDE, XFCE and Cinnamon show the tray icon as is. GNOME needs the AppIndicator extension. Without a tray, “hide to tray” minimizes the window.
  • Display. AltPing needs X11. It runs under Wayland through XWayland, which GNOME and KDE have. glibc-based distributions only (not Alpine).
  • Uninstall. Packages are removed with the package manager. The quick install adds Uninstall to the menu entry (right-click) and leaves ~/.altbins/.altping-uninstall.sh.
