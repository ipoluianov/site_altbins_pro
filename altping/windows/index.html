First start

  1. Run altping.exe from any folder. It works right away, nothing needs to be installed.
  2. The exe is not signed, so on the first start SmartScreen may say “Windows protected your PC”. Click More info, then Run anyway.
  3. Optional: the Install link in the status bar copies AltPing into %USERPROFILE%\.altbins and adds it to the Start menu, the desktop and “Installed apps”. When you start a newer download, the link reads Update. Remove AltPing from “Installed apps” or with the Uninstall link.
