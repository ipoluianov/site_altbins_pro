About AltBins

I’m Ivan Poluianov, and I have always valued software that is easy to install. Download one file, run it, and it works: no installer, no runtime to set up first, nothing pulled from the internet on the first start.

AltBins is a set of small desktop utilities built around that idea. They are native apps. There is no Electron with a whole browser inside, no .NET or Java to install, no background services. Each tool does one job and stays out of the way.

One file

On Windows and Linux every utility is a single portable executable. Keep it in a tools folder or on a USB stick.

No heavy runtime

No Electron, no .NET, no Java. Nothing extra to download, nothing to keep updated next to the app.

Install only if you want

Run it from any folder. If you like, it adds itself to the Start menu or the app menu, and removes itself just as easily.

Windows, macOS, Linux

A portable .exe, a signed and notarized .dmg for Apple Silicon, and Linux builds for x64 and arm64 with .deb and .rpm packages.

12 languages

Every app speaks 12 languages and comes with a light and a dark theme.

Free and open source

MIT license, code on GitHub. Downloads come straight from GitHub releases.

Install, settings, removal

Windows

Install is optional. The .exe runs from any folder. The Install link in the status bar copies it into %USERPROFILE%\.altbins and adds it to the Start menu, the desktop and “Installed apps”.

Remove it from “Installed apps” or with the Uninstall link. A portable copy is removed by deleting the file.

macOS

Install: open the .dmg and drag the app to Applications. It is signed and notarized, so Gatekeeper lets it open without warnings.

Remove: drag the app from Applications to the Trash.

Linux

Install is optional. The portable binary runs from anywhere. The one-line install puts the app into ~/.altbins for the current user, without root, and adds a menu entry. The .deb and .rpm packages install system-wide.

Remove: Uninstall in the menu entry (right-click) or ~/.altbins/.<app>-uninstall.sh. Packages are removed with the package manager.

Settings in one place

Each app keeps its settings, lists and history in its own folder in your home folder: ~/.altbins/.altping, ~/.altbins/.althex (on Windows, %USERPROFILE%\.altbins\…). Delete that folder to reset the app, or to clean up after removing it.

Your data stays with you

The apps collect no statistics and send nothing anywhere unless you ask them to. AltPing contacts only the hosts you add, and publishes a host’s ping time to u00.io only when you turn that on. The AltHex API and MCP server for AI agents are off until you switch them on, and then listen only on your own computer.

Source code and building

Every utility is open source under the MIT license. To build any of them you need only the Go compiler: no cgo, no C toolchain, no system libraries to install. Clone the repository and run go build:

git clone https://github.com/ipoluianov/altping && cd altping && go build .

Without cgo, Go builds for every system from any of them. For example, a Windows .exe on Linux or macOS:

GOOS=windows GOARCH=amd64 go build -ldflags=-H=windowsgui .

build/all.sh in each repository builds every platform the way the releases are made, with the .deb and .rpm packages and the install script.
