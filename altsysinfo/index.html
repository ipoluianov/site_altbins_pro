About

AltSysInfo is a small GUI app that shows what is inside a computer and how it is set up. The CPU, memory modules, drives and volumes, graphics adapters and displays, network adapters, PCI and USB devices, audio, sensors and battery are sorted into categories on the left. Any value is copied with one click, and the main facts are saved as a PDF report. On Linux it works without root rights.

What it does

Memory modules

The size, speed and model of every memory stick, not just the total.

Drives and volumes

Each drive with its model, type and size, and the free space on every volume.

Graphics and displays

Graphics adapters with video memory and drivers, and the monitors connected to them.

PCI and USB devices

Every device with its ID and driver, to find what is installed and what it uses.

Sensors and battery

Temperatures the system reports, and the state of the battery on a laptop.

Copies in one click

A button next to every value puts it into the clipboard.

Makes a PDF report

The CPU, memory, drives and graphics in one document, for a support request or the computer's papers.

Looks up PCI IDs

Find a vendor or device by its ID or name in the built-in database, without the internet.

Speaks your language

Available in 31 languages, with a light or dark look.
